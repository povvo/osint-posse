# Research inputs

This directory contains original synthesis and private release inputs. Raw PDFs
and export JSON are ignored by default and are not admitted to the initial
public import.

An artefact may be admitted only when `provenance.csv` records its path, source,
author, licence, retrieval date, SHA-256, purpose, and an explicit `yes`
redistribution decision. Unknown rights mean no redistribution. The ledger can
record a decision; it cannot manufacture permission.

Keep public citations and original synthesis where they are useful. Keep
restricted source files outside release staging.
